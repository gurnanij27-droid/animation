# Animation 
# CSS Animation Examples
About the Project

This project demonstrates different CSS animations created using HTML and CSS. It shows how CSS animations can add movement, color changes, and visual effects to web elements.

# Technologies Used
HTML5
CSS3
# Features
Color-changing animation
Moving animation
Rotating animation
Pulse animation
Fade animation
Loading spinner animation
Square path animation
Google-style bouncing dots animation
# Animation Types
Color Animation: Changes the background color of a box.
Move Animation: Moves an element up and down.
Rotate Animation: Rotates a box in different directions.
Pulse Animation: Increases and decreases the size of a box.
Fade Animation: Changes the opacity of an element.
Loading Animation: Rotates a circular loading indicator.
Square Path Animation: Moves a box along a square path.
Google Animation: Displays bouncing colored circles.
# How to Run
Save the code as animation.html.
Open the file in any web browser.
Watch the different CSS animations.
